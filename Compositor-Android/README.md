# Compositor Android

Android-native image editor project inspired by the workflow and feature set described by the MIT-licensed robbietilton/Compositor project.

## Current MVP
- Dark editing workspace
- File/Edit/Image/Layer/Select/Filter/View/Help menus
- Move, Brush, Eraser, Rectangle, Ellipse, Text, Eyedropper, Hand
- Multiple layers with opacity and blend mode
- Open image from device
- Export PNG/JPG
- Zoom controls

## Build
Open the `Compositor-Android` folder in Android Studio and run the `app` configuration on Android 8.0+.

This is an independent Android implementation and does not include the original macOS source code.
